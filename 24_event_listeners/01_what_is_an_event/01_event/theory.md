# 1. What is an Event?

**Events** are one of the foundations of interactive interfaces on the web.

Without events, a web page would be almost like a static document: it could show information, but it couldn't react when the user clicks, types, moves the mouse, submits a form, or when the browser finishes loading the page.

An event is simply a **signal** that something has happened.

When something happens, we say that an event has "fired" or "triggered". JavaScript allows us to "listen" for these events and execute code in response.
