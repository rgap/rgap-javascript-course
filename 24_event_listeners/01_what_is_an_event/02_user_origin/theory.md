# 2. Origin of Events (User)

Events can occur due to different causes. The most common ones are generated by the user.

### Events caused by the user

These are events that happen when the user interacts with the page.

For example:
* Clicking a button (`click`).
* Typing in a text field (`keydown`, `keyup`, `input`).
* Moving the mouse over an element (`mousemove`, `mouseenter`).
* Scrolling the page (`scroll`).
* Submitting a form (`submit`).
