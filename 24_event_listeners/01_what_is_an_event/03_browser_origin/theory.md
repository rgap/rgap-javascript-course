# 3. Events caused by the browser

These are events that happen due to internal browser actions or changes in the page state.

For example:
* The page finished loading the HTML (`DOMContentLoaded`).
* All resources (images, CSS) finished loading (`load`).
* The window was resized (`resize`).
* The user scrolled the window (`scroll`).
* The user is trying to leave the page (`beforeunload`).
